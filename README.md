# SwiftCapture
**SwiftCapture** is a Windows screen recorder that uses DXGI Desktop Duplication to capture your screen, with hardware H.264 encoding when supported. Choose your output resolution and frame rate, preview your screen, and add draggable text or image overlays.

It includes separate controls for desktop and microphone audio, an adjustable audio-sync setting, and a dark interface with a shortcut to your recordings folder. Requires Windows and compatible graphics drivers; available hardware-encoding options depend on your PC. This is an early version, so test a short recording first to check performance and audio levels on your setup.
